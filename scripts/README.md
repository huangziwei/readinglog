# Diagnostics script

Place `dumplogs.sh` to `/mnt/us/documents/`, if your jailbreak support Scriptlet, you can tap it in the library or home (it will appear in the library as a coverless "ReadingLog Diagnostics"), or Scriptlet is not supported, you can run it in Kterm with `sh /mnt/us/documents/dumplogs.sh`. After it finished, send me the `dumplogs.zip` file in `/mnt/us/` either via issue or email.
